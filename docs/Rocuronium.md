# Rocuronium
= **Nicht-depolarisierendes Muskelrelaxans**
(*Stand: 06.05.2026*)

> [!warning] Achtung
> Rocuronium ist **mit Vorsicht anzuwenden** bei:
> - **Schwere Leberinsuffizienz** (Wirkverlängerung!)
> - **Niereninsuffizienz** (leicht verlängerte WD)
> - **Allergie gegen Rocuronium oder Bromid**
> - **Schwangerschaft** (nur bei strenger Indikation)

---
## 💬 KURZ
- **Schnell wirkendes, nicht-depolarisierendes Muskelrelaxans**  
- **Wirkungseintritt**: 
	- normale Dosierung (0,6 mg/kg): ~2 Min.  
	- RSi-Dosierung (1,2 mg/kg): ~45 Sek.
- **Wirkdauer**: **20–60 Min.**  
	- dosisabhängig: 
		- 0,6 mg/kg → ~20–35 Min.  
		- 1,2 mg/kg → ~30–60 Min.  
- **Antagonisierbar**: ✅ **Ja (Sugammadex)**  

---
## 💊 DOSIERUNG
| **Indikation**              | **Dosierung**          | **Hinweise**                                                      |
| --------------------------- | ---------------------- | ----------------------------------------------------------------- |
| **Standard-Intubation**     | **0,6 mg/kg i.v.**     | Bei 70 kg: **42 mg**                                              |
| **Notfallintubation (RSI)** | **1,0–1,2 mg/kg i.v.** | WE: **~45–60 Sek.** (ähnlich [Succinylcholin](Succinylcholin.md)) |
| **Kinder (1–12 J.)**        | **0,6–1,0 mg/kg i.v.** | WE: ~60–90 Sek.                                                   |
| **Säuglinge (< 1 J.)**      | **0,6–0,8 mg/kg i.v.** | Höhere Empfindlichkeit!                                           |
| **Erhaltung**               | **0,1–0,2 mg/kg i.v.** | Alle **15–20 Min.** (nach Bedarf)                                 |
| **IM-Injektion**            | **Nicht empfohlen**    | Unvorhersehbare Resorption                                        |

> [!tip] **Maximaldosis**: **Keine feste Obergrenze** – Titration nach Wirkung (Monitoring: TOF).

---
## ⚗️ PHARMAKOLOGIE
| **Parameter**            | **Wert**                                             |
| ------------------------ | ---------------------------------------------------- |
| **WE** 🧭                | **0,6 mg/kg → ~2 Min.**<br>**1,2 mg/kg → ~45 Sek.**  |
| **WD** ⏳                 | **0,6 mg/kg: ~20–35 Min.<br>1,2 mg/kg: ~30–60 Min.** |
| **Elimination**          | **80% hepatisch** (CYP3A4)<br>**20% renal**          |
| **Formulierung**         | 10 mg/ml Lösung                                      |
| **Plasmaproteinbindung** | ~60–80%                                              |

---
## ⚡ ANTAGONISIERUNG MIT SUGAMMADEX
| **Blockadetiefe**                    | **TOF-Status**                         | **Sugammadex-Dosis**            | **Erholungszeit (TOFR ≥ 0,9)** |
| ------------------------------------ | -------------------------------------- | ------------------------------- | ------------------------------ |
| **Leichte Blockade**                 | **4 Twitches** (TOFR **< 0,4**)        | **0,22–1 mg/kg**<br>≈0,5–1 Amp. | **~1–2 Min.**                  |
| **Moderate Blockade**                | **2–3 Twitches**                       | **2 mg/kg**<br>≈1–2 Amp.        | **~2–3 Min.**                  |
| **Tiefe Blockade**                   | **1 Twitch oder 0 Twitches + PTC 1–5** | **4 mg/kg**<br>≈2 Amp           | **~3–5 Min.**                  |
| **Vollständige Blockade (nach RSI)** | **0 Twitches + PTC > 5**               | **16 mg/kg**<br>≈6 Amp.         | **~1–3 Min.**                  |

#### **Wichtige Hinweise:**
1. **TOF-Monitoring ist essenziell!**
	- **Ziel:** **TOF-Ratio (TOFR) ≥ 0,9** (vollständige Erholung).
	- **Sugammadex wirkt 1:1 mit Rocuronium** (molekulare Kapselbildung).

2. **Dosisanpassungen:**
	- **Adipöse Patienten:** **Dosis nach tatsächlichem Körpergewicht** (nicht Idealgewicht!)  
	- **Niereninsuffizienz:** **Keine Dosisanpassung nötig**  
	- **Leberinsuffizienz:** **Keine Dosisanpassung nötig**  

3. **Kontraindikationen für Sugammadex:**
	- **Schwere Allergie gegen Sugammadex**  
	- **Schwangerschaft** (strenge Indikation, wegen Datenlage)  

---
## ✨ WIRKMECHANISMUS
- **Kompetitiver Antagonist** an **nikotinischen Acetylcholinrezeptoren** (motorische Endplatte).
- **Keine Depolarisation** → **Keine Faszikulationen** (im Gegensatz zu [Succinylcholin](Succinylcholin.md)).
- **Wirkung**:
	- Blockade der **Neuromuskulären Übertragung** → **Muskelrelaxation**.
	- **Kein Effekt auf das ZNS** (keine Sedierung/Analgesie).

---
## ✅ VORTEILE
- **Schneller Wirkungseintritt**  
	→ bei hoher Dosis ~45–60 Sek.  
	→ RSI-Alternative zu [Succinylcholin](Succinylcholin.md)  
- **Antagonisierbar** mit **Sugammadex**  
- **Keine Faszikulationen** (kein Muskelzucken).
- **Kein [Hyperkaliämie](Kalium.md)-Risiko** (im Gegensatz zu [Succinylcholin](Succinylcholin.md))  
- **Gute Steuerbarkeit** (Titration möglich)  

---
## ⚠️ NEBENWIRKUNGEN
| **Nebenwirkung**           | **Häufigkeit**            | **Management**                                         |
| -------------------------- | ------------------------- | ------------------------------------------------------ |
| **Bradykardie**            | **Selten** (~5%)          | **Atropin 0,5–1 mg i.v.** (bei Bedarf)                 |
| **Hypotension**            | **Selten** (~3%)          | **Volumengabe, Vasopressoren**                         |
| **Allergische Reaktionen** | **Sehr selten**           | **Adrenalin, Kortison, Antihistaminika**               |
| **Verlängerte WD**         | **Bei Leberinsuffizienz** | **Dosis reduzieren, Monitoring**                       |
| **Injektionsschmerz**      | **Häufig** (~30%)         | **Langsame Injektion, [Acetazolamid](Acetazolamid.md)-Zusatz** |

---
## ❌ KONTRAINDIKATIONEN
- **Absolut**:
	- **Allergie gegen Rocuronium oder Bromid**
- **Relativ**:
	- **Schwere Leberinsuffizienz** (Wirkverlängerung)
	- **Niereninsuffizienz** (leicht verlängerte WD)
	- **Schwangerschaft** (nur bei strenger Indikation)
	- **Säuglinge < 3 Monate** (erhöhte Empfindlichkeit)

---
## 🔄 WECHSELWIRKUNGEN
| **Substanzklasse**                                           | **Effekt**                           | **Management**                    |
| ------------------------------------------------------------ | ------------------------------------ | --------------------------------- |
| **Volatile Anästhetika** (z. B. [Sevofluran](Sevofluran.md)) | **Wirkverstärkung** (~20–30%)        | **Dosis reduzieren** (um ~25%)    |
| **Opioide** (z. B. Fentanyl)                                 | **Wirkverstärkung** (leicht)         | Keine Dosisanpassung nötig        |
| **Aminoglykoside**                                           | **Wirkverstärkung** (additiv)        | **Monitoring verstärken**         |
| **Magnesium**                                                | **Wirkverstärkung**                  | **Dosis reduzieren**              |
| **Kortikosteroide**                                          | **Wirkabschwächung** (chronisch)     | **Dosis erhöhen** (ggf.)          |
| **Sugammadex**                                               | **Sofortige Aufhebung** der Blockade | **16 mg/kg i.v.** (Standarddosis) |
