# Succinylcholin
= **Depolarisierendes Muskelrelaxans**
(*Stand: 06.05.2026*)

> [!warning] Achtung!
> Succinylcholin ist **kontraindiziert** bei:
> - **[Maligne Hyperthermie](Maligne-Hyperthermie.md)** (MH)
> - **Verbrennungen >24h alt** ([Hyperkaliämie](Kalium.md)-Risiko!)
> - **Muskeldystrophien** (Duchenne, Becker)
> - **Schwere [Hyperkaliämie](Kalium.md)** (K⁺ > 5,5 mmol/l)
> - **Penetrierende Augenverletzungen** (IOP↑)
> - **Akute Niereninsuffizienz** (relativ)

---
## 💬 KURZ
- **Schnellster Wirkungseintritt** aller Muskelrelaxanzien
	→ **20–30 Sekunden** (i.v.)
- **Depolarisierender Mechanismus**: 
	→ Bindet an nikotinische Acetylcholinrezeptoren → **persistierende Depolarisation** → **Faszikulationen** → **Lähmung**
- **Kurze Wirkdauer**
	→ 5–10(–12) Min. 
	→ Ideal für **Notfallintubation** (RSI)
- **Keine Antagonisierbarkeit**  

---
## 💊 DOSIERUNG
| **Indikation**              | **Dosierung**               | **Hinweise**                                    |
| --------------------------- | --------------------------- | ----------------------------------------------- |
| **Standard**                | **1 mg/kg i.v.**            | Bei 70 kg: **70 mg**                            |
| **Notfallintubation (RSI)** | **1,5–2 mg/kg i.v.**        | Schnellere Wirkung (WE: **~20 Sek.**)           |
| **Kinder**                  | **2 mg/kg i.v.**            | Höhere Dosis nötig (WE: ~20–30 Sek.)            |
| **IM-Injektion**            | **3–4 mg/kg** (max. 150 mg) | WE: **2–3 Min.**; nur bei fehlendem i.v.-Zugang |

> [!tip] **Maximaldosis**: **200 mg** (Erwachsene, i.v.)

---
## ⚗️ PHARMAKOLOGIE
| **Parameter**       | **Wert**                                  |
|---------------------|------------------------------------------|
| **WE** 🧭           | **20–30 Sek.** (i.v.)<br>**2–3 Min.** (i.m.) |
| **WD** ⏳           | **5–7 Min.** (1 mg/kg)<br>**10–12 Min.** (2 mg/kg) |
| **Metabolismus**    | **Plasma-Cholinesterase** (90%)<br>Spontan (10%) |
| **Elimination**     | **Succinylmonocholin** (renal)          |
| **Formulierung**    | 20 mg/ml oder 100 mg/ml Lösung           |

---
## ✨ WIRKMECHANISMUS
1. **Depolarisation**:
	   - Succinylcholin bindet an **nikotinische Acetylcholinrezeptoren** (motorische Endplatte)
	   → **persistierende Depolarisation** (keine Repolarisation möglich)
2. **Faszikulationen**:
	   - Initial **Muskelzuckungen** (sichtbar, ~20–30 Sek. nach Gabe)
3. **Lähmung**:
	   - **Phase-I-Block**: Depolarisationsblock (keine Erregungsweiterleitung)
	   - **Phase-II-Block**: Bei Überdosierung (> 4 mg/kg kumulativ) oder längerer Gabe (selten, nicht-depolarisierend)

---
## ✅ VORTEILE
- **Schnellster Wirkungseintritt** aller Muskelrelaxanzien 
	- **20–30 Sek.**)
- **Sehr kurze Wirkdauer** (5–12 Min.)  
	- Ideal für **Notfallintubation** (RSI)
- **Keine kumulative Wirkung**  
	- schneller Abbau durch Cholinesterase

---
## ⚠️ NEBENWIRKUNGEN
| **Nebenwirkung**                                    | **Häufigkeit**         | **Management**                                               |
| --------------------------------------------------- | ---------------------- | ------------------------------------------------------------ |
| **Faszikulationen**                                 | **Sehr häufig** (~90%) | **Keine Präcurarisierung**, (veraltet)                       |
| **[Hyperkaliämie](Kalium.md)**                      | **Selten***            | **Kontraindikation bei Risikopatienten!**                    |
| **[Maligne-Hyperthermie](Maligne-Hyperthermie.md)** | **Selten**             | **[Dantrolen](Dantrolen.md) bereithalten!** (2,5 mg/kg i.v.) |
| **Bradykardie/Asystolie**                           | **Selten** (~1–2%)     | **Atropin 0,5–1 mg i.v.** (bei Kindern: 0,02 mg/kg)          |
| **Myalgien**                                        | **Häufig** (~40%)      | **NSAIDs postoperativ** (z. B. Ibuprofen 400 mg)             |
| **Histaminfreisetzung**                             | **Sehr selten**        | Keine spezifische Therapie nötig                             |

\*Risiko↑ bei: **Verbrennungen >24h**, **Muskeldystrophien**, **Nierenversagen**, **Immobilisation >7 Tage**

---
## ❌ KONTRAINDIKATIONEN
- **Absolute Kontraindikationen**:
	- **[Maligne-Hyperthermie](Maligne-Hyperthermie.md)** (MH) in der Anamnese
	- **Verbrennungen >24h alt** ([Hyperkaliämie](Kalium.md)-Risiko!)
		- Verbrennung vor <24h →  kein Problem 👍
		- Aber die Kontraindikation **gilt für mindestens 1 Jahr!**  
	- **Muskeldystrophien** (Duchenne, Becker, myotonische Dystrophie)
	- **Schwere [Hyperkaliämie](Kalium.md)** (K⁺ > 5,5 mmol/l)
	- **Penetrierende Augenverletzungen** (IOP↑)
	- **Allergie gegen Succinylcholin**
- **Relative Kontraindikationen**:
	- **Akute Niereninsuffizienz**
	- **Schwere Leberinsuffizienz** (verlängerter Abbau)
	- **Schwangerschaft** (nur bei strenger Indikation)
	- **Säuglinge < 3 Monate** (erhöhtes Bradykardie-Risiko)

---
## 🔄 WECHSELWIRKUNGEN
| **Substanzklasse**                                                     | **Effekt**                                    | **Management**                             |
| ---------------------------------------------------------------------- | --------------------------------------------- | ------------------------------------------ |
| **Cholinesterasehemmer** (z. B. Neostigmin, Physostigmin)              | **Wirkverlängerung!** (bis zu 2x)             | **Dosis reduzieren** oder vermeiden        |
| **Atropin**                                                            | **Bradykardie-Risiko↑**                       | **Atropin vorab geben** (0,5–1 mg i.v.)    |
| **Volatile Anästhetika** (z. B. Halothan, [Sevofluran](Sevofluran.md)) | **[MH](Maligne-Hyperthermie.md)-Risiko↑**     | **[Dantrolen](Dantrolen.md) bereithalten** |
| **Lithium**                                                            | **Wirkverlängerung** (Cholinesterase-Hemmung) | **Dosis anpassen**                         |
| **Magnesium**                                                          | **Wirkverstärkung**                           | **Dosis reduzieren**                       |
| **Aminoglykoside**                                                     | **Wirkverstärkung**                           | **Monitoring verstärken**                  |
| **Kortikosteroide**                                                    | **Hyperkaliämie-Risiko↑**                     | **K⁺-Werte kontrollieren**                 |
