# Sepsis

---

## 🚨 CAVE / MERKE 💡
- Sepsis = **SOFA‑Δ ≥2 + Infektion**  
- qSOFA = **Risikoscreening bei Infektionsverdacht**  
	→ **nicht zur Diagnosestellung geeignet**, SOFA nutzen  
- Laktat frühzeitig bestimmen (Perfusionsmarker)  
- Blutkulturen **vor** Antibiose  
- Mortalität:  
	- Sepsis ~25 %  
	- Septischer Schock ~50 %  

> [!tip]- 🕐 One‑Hour‑Bundle
> **Innerhalb der ersten Stunde:**
> 
> **1. Laktat messen**  
> → bei Erhöhung: Wiederholung nach 2–4 h  
> 
> **2. Blutkulturen abnehmen**  
> → vor Beginn der Antibiose  
> 
> **3. Breitspektrum‑Antibiose starten**  
> → innerhalb von 60 Minuten, 4,5 g Pip/Taz, 1-1-1
> 
> **4. Flüssigkeitstherapie beginnen**  
> → 30 ml/kg balancierte Kristalloide bei Hypotonie oder Laktat ≥4 mmol/l  
> 
> **5. Vasopressoren bei Bedarf**  
> → Noradrenalin, wenn MAP <65 mmHg trotz Flüssigkeit  
> 
> **Ziel:** schnelle hämodynamische Stabilisierung & frühe Fokuskontrolle

## 📖 DEFINITION
#### Sepsis
> **Lebensbedrohliche Organdysfunktion durch eine fehlregulierte Wirtsantwort auf eine Infektion.**

#### Septischer Schock
= Sepsis + Katecholamine nötig + Laktat ≥2 mmol/l (≈18 mg/dl 😉)

> [!info]- Frühere SIRS-basierte Definition
> #### SIRS
> 1. Körpertemperatur ≥38 °C oder ≤36 °C  
> 2. Herzfrequenz ≥90/min  
> 3. AF ≥20/min oder PaCO₂ ≤33 mmHg  
> 4. Leukozytopenie / -zytose oder Linksverschiebung ≥10 % stabkernige Neutrophile  
>
> #### Sepsis (alt)
> 1. **Sepsis** = SIRS + Verdacht auf Infektion  
> 2. **Schwere Sepsis** = Sepsis + Organdysfunktion  
> 3. **Septischer Schock** = schwere Sepsis + Hypotonie (MAP <65 mmHg)

## 🧩 EINTEILUNG

#### 1. qSOFA
- v. a. für Rettungsdienst & Notaufnahme  
- ≥2 Punkte → **hohes Risiko für schweren Verlauf**

| Kriterium     | Schwelle    |
| ------------- | --------- |
| Atemfrequenz  | ≥22/min     |
| [GCS](GCS.md) | <15         |
| syst. RR      | ≤100 mmHg   |

#### 2. SOFA
- **Sepsis liegt vor, wenn eine akute SOFA‑Verschlechterung um ≥2 Punkte im Rahmen einer Infektion auftritt.**  
- Mortalitätsanstieg um ~10 % je zusätzlichem Punkt  
- Ausgangswert: 0 Punkte  

|                                       | 0 Punkte     | 1 Punkt      | 2 Punkte                  | 3 Punkte                          | 4 Punkte                          |
| ------------------------------------- | ------------ | ------------ | ------------------------- | --------------------------------- | --------------------------------- |
| **ZNS** 🧠<br>[GCS](GCS.md)           | 15           | 14–13        | 12–10                     | 9–6                               | <6                                |
| **Herz** ❤️                           | MAP ≥70 mmHg | MAP <70 mmHg | Dopamin ≤5 oder Dobutamin | NOR ≤0,1 µg/kg/min<br>≈ <0,5 mg/h | NOR >0,1 µg/kg/min<br>≈ >0,5 mg/h |
| **Lunge** 🫁<br>PaO₂/FiO₂             | ≥400         | <400         | <300                      | <200 (mit Beatmung)               | <100 (mit Beatmung)               |
| **Niere** 🫘<br>Kreatinin<br>\[mg/dl] | <1,2         | 1,2–1,9      | 2,0–3,4                   | 3,5–4,9 oder Diurese <500 ml/d    | ≥5,0 oder Diurese <200 ml/d       |
| **Leber** 🟧<br>Bilirubin<br>\[mg/dl] | <1,2         | 1,2–1,9      | 2,0–5,9                   | 6,0–11,9                          | ≥12,0                             |
| **Gerinnung** 🩸<br>Thrombos          | ≥150 000/µl  | <150 000/μl  | <100 000/μl               | <50 000/μl                        | <20 000/μl                        |

## ⚙️ PATHOPHYSIOLOGIE
1. Lokale Inflammation  
2. Vasodilatation & Zytokinfreisetzung  
3. Kapillarleck → relative Hypovolämie  
4. Endothelschaden → Koagulopathie (DIC‑ähnlich)  
5. Multiorganversagen → Tod

> [!info]- Ausführlichere Pathophysiologie
> 1. **Infektion & lokale Immunantwort**  
>    - Erregererkennung über [PRRs](PRR.md) (z. B. TLRs)  
>    - Freisetzung proinflammatorischer Mediatoren (TNF‑α, IL‑1, IL‑6)  
>
> 2. **Systemische Inflammation**  
>    - Zytokinsturm → Vasodilatation  
>    - Erhöhte Gefäßpermeabilität → Kapillarleck  
>    - Relative Hypovolämie trotz normalem Blutvolumen  
>
> 3. **Endotheliale Dysfunktion**  
>    - Barrierestörung → Ödeme  
>    - Verlust der Mikrozirkulationsregulation  
>    - NO‑Überproduktion → Vasoplegie  
>
> 4. **Koagulopathie & DIC‑ähnliche Veränderungen**  
>    - Aktivierung der Gerinnung  
>    - Verbrauch von Thrombozyten & Gerinnungsfaktoren  
>    - Mikrothromben → Organhypoperfusion  
>
> 5. **Mitochondriale Dysfunktion**  
>    - Gestörte ATP‑Produktion  
>    - „Zytopathische Hypoxie“ trotz ausreichender Sauerstoffzufuhr  
>
> 6. **Immunparalyse (späte Phase)**  
>    - Erschöpfung der Immunzellen  
>    - Erhöhte Anfälligkeit für sekundäre Infektionen  
>
> 7. **Multiorganversagen**  
>    - Kombination aus Hypoperfusion, Mikrothromben, mitochondrialer Dysfunktion  
>    - Progression zu Schock, Organversagen und Tod

## 🦠 INFEKTIOLOGIE

#### 1. Häufigste Erreger

| Kategorie                      | Erregergruppe                                                     | Prozente    |
| ------------------------------ | ----------------------------------------------------------------- | ----------- |
| **Gramnegative<br>(~50–60 %)** | *Escherichia coli*                                                | **20–25 %** |
|                                | *Klebsiella* spp.                                                 | 10–15 %     |
|                                | *Pseudomonas aeruginosa*                                          | 5–10 %      |
| **Grampositive<br>(~30–40 %)** | *Staphylococcus aureus*                                           | **10–15 %** |
|                                | *Streptococcus* spp.                                              | 10–15 %     |
|                                | Koagulase‑negative Staphylokokken<br>⚠️ häufig Kontaminationen    | 5–10 %      |
| **Pilze<br>(~5–10 %)**         | *Candida* spp.                                                    | 5–10 %      |

#### 2. Häufigste Infektionsorte

| Infektionsfokus                         | Anteil       |
| --------------------------------------- | ------------ |
| **Respirationstrakt**                   | **~35–45 %** |
| **Abdomen**                             | **~20–25 %** |
| **Harnwege**                            | **~10–15 %** |
| **Primäre Blutbahninfektion**           | ~10 %        |
| **Haut / Weichteile**                   | ~5–10 %      |
| **Katheter / Fremdmaterial**            | ~5–10 %      |
| **ZNS** → meist Meningitis/Enzephalitis | <5 %         |

> [!tip] Klinische Relevanz  
> - Pneumonie ist **mit Abstand** der häufigste Sepsis‑Auslöser.  
> - Fremdmaterial (ZVK, Port, ADM, Drainagen) ist ein **wichtiger Fokus**, besonders bei nosokomialen Infektionen.  
> - Urosepsis ist häufig bei älteren Patienten.

## 🩺 DIAGNOSTIK 

#### 1. Scores 📊
- qSOFA (s. oben)  
	→ zum Erkennen von Risikopatienten  
- SOFA (s. oben)  
	→ zur Diagnose einer Sepsis  

#### 2. Labor 🧪  
- **Laktat**  
	→ frühzeitig bestimmen  
	→ wenn initial erhöht: Kontrolle nach 2–4 h  
- **CRP**  
	→ unspezifisch, Verlauf hilfreich  
- **PCT**  
	→ erhöht bei bakteriellen Infektionen  
	→ hilfreich zur Therapiedauer  
- **Blutbild**  
	→ Leukozytose/Leukopenie  
	→ Thrombozytopenie (DIC‑Hinweis)  
	→ Hb‑Abfall bei Verbrauch/Blutung  
- **Gerinnung**  
	→ INR ↑  
	→ aPTT ↑  
	→ D‑Dimere ↑  
	→ AT‑III ↓  
- **Nierenwerte**  
	→ Kreatinin ↑  
	→ Harnstoff ↑  
	→ Oligurie/Anurie  
- **Leberwerte**  
	→ Bilirubin ↑  
	→ Transaminasen ↑  
	→ Quick/INR ↑  
- **Elektrolyte**    
	→ [Hyperkaliämie](Kalium.md) bei Nierenversagen  
	→ Hypokalzämie bei schwerer Sepsis  
- **BGA**  
	→ Laktat  
	→ metabolische Azidose  
	→ Hypoxie  

#### 3. Mikrobiologie 🧫 
- Blutkulturen **vor** Beginn der Antibiose  
	→ i. d. R. 2 Paare (aerob & anaerob)  
- Trachealsekret  
- Urinstatus  
- Wundsekret  
- Abstriche von Drainagen  
- Gewechselte Katheter (ADM, ZVK)  
- Liquor  

#### 4. Fokussuche 🎯

| Fokusbereich | Diagnostik |
|--------------|------------|
| **ZNS** 🧠 | Klinik, CT/MRT, Liquor |
| **Lunge** 🫁 | Röntgen‑Thorax, Bronchoskopie |
| **Herz** ❤️ | TTE/TEE |
| **GIT** 🍽️ | Sonografie |
| **Nieren** 🫘 | Urinstatus, Sonografie (Rückstau?), DK wechseln + Mikrobiologie |
| **Fremdmaterial** 🧵 | ZVK, ADM, Drainagen |

  <strong style="color:#1e88e5;">💦 Volumentherapie:</strong><br>
  → Kein HES, kein NaCl ❌<br>
  → Balancierte Kristalloide ✅<br>
  → Bei Stabilisierung: Entwässerung erwägen 💡
</div>

<div style="border:2px solid #e53935; background-color:rgba(244,67,54,0.1); padding:12px; border-radius:8px; margin-top:8px;">
  <strong style="color:#e53935;">❤️‍🔥 Vasopressoren:</strong><br>
  → Noradrenalin = First-Line<br>
  → Vasopressin ggf. additiv (0,01–0,03 U/min)<br>
  → Hydrocortison 200 mg/d nur bei persistierendem Schock
</div>

<div style="border:2px solid #26c6da; background-color:rgba(38,198,218,0.1); padding:12px; border-radius:8px; margin-top:8px;">
  <strong style="color:#26c6da;">🫁 Lunge:</strong><br>
  → SpO₂ 90–96%<br>
  → Tidalvolumen 4–6 ml/kg<br>
  → Driving Pressure <15 mmHg<br>
  → PEEP individuell, kein pauschal „hoch“<br>
  → Relaxierung nur bei schwerem ARDS
</div>

<div style="border:2px solid #43a047; background-color:rgba(76,175,80,0.1); padding:12px; border-radius:8px; margin-top:8px;">
  <strong style="color:#43a047;">🦠 Antiinfektiva:</strong><br>
  → Blutkulturen vor Antibiose<br>
  → Kalkulierte Antibiose innerhalb 1 h<br>
  → Dauer meist 7 Tage<br>
  → MRSA: Linezolid oder Vancomycin<br>
  → Antimykotika nur bei Risikokonstellation/Nachweis
</div>

<div style="border:2px solid #fbc02d; background-color:rgba(255,235,59,0.1); padding:12px; border-radius:8px; margin-top:8px;">
  <strong style="color:#fbc02d;">🍽️ Ernährung & Supplemente:</strong><br>
  → Früh enteral, zurückhaltend im Schock<br>
  → Keine Routinegabe von Vitamin C, D, Selen, L‑Carnitin<br>
  → Thiamin erwägen bei Mangel/Laktatazidose
</div>

<div style="border:2px solid #6d4c41; background-color:rgba(121,85,72,0.1); padding:12px; border-radius:8px; margin-top:8px;">
  <strong style="color:#6d4c41;">📌 Sonstiges:</strong><br>
  → Thromboseprophylaxe obligat<br>
  → Keine starren Zielwerte (ScvO₂, Hämatokrit)<br>
  → Fokuseradikation immer prüfen (ZVK, OP, Wunden)
</div>
